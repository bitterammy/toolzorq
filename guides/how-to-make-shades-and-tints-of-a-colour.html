How to Make Shades and Tints of a Colour — Build a Simple Palette from One Colour

Short answer: a tint is your colour mixed with white, a shade is your colour mixed with black, and a tone is your colour mixed with grey. To make a 20 percent tint, move each RGB channel 20 percent of the way toward 255; to make a 20 percent shade, multiply each channel by 0.8. One colour is rarely enough. A website, a slide deck, a poster, or a social post needs a light background, a darker heading, a hover state for a button, and a border that is visible without shouting. The professional way to get all of those is not to pick five unrelated colours and hope they match. It is to start with one colour you like and make its shades and tints. Every step on that scale belongs to the same family, so the result looks deliberate even when you have never studied colour theory. This guide explains what shades, tints and tones are, the exact maths behind them, how to work them out by hand, and how to build a simple five-colour palette in a minute with TOOLZORQ's Color Picker.

What is a shade, a tint, and a tone?

The three words describe three different mixtures, and mixing them up is the most common mistake in this whole subject. A tint is a colour mixed with white. It gets lighter and softer. A pale blue wash behind a heading is a tint of the blue. A shade is a colour mixed with black. It gets darker and heavier. The deep navy of a footer is a shade of the blue. A tone is a colour mixed with grey. It gets duller and less saturated, without getting much lighter or darker. A muted, dusty blue is a tone of the blue.

All three start from the same base colour, which designers call the base or pure colour. A base of #3B7DD8, a medium blue, can give you a whole family: tints up to almost white, shades down to almost black, and tones in between that look grey-blue. The family stays harmonious because every member contains the same base colour, just with more white, more black, or more grey added. That is the entire secret of a matching palette, and it is why a scale built from one colour almost always looks better than five colours picked separately.

One more distinction matters in practice. A tint and a lighter colour are not the same thing. Picking a different, lighter blue from a colour chart gives you a new colour with its own hue. Making a tint of your blue keeps the hue and only changes the lightness. The same goes for shades. If your brand blue is #3B7DD8, its 20 percent tint is still recognisably that blue, only lighter. A random light blue from a chart may lean purple or green, and that small shift is what makes a design look slightly off.

The maths: how shades and tints are calculated

On a screen, a colour is three numbers: red, green and blue, each from 0 to 255. The HEX code is the same three numbers written in base 16. The blue #3B7DD8 is red 59, green 125, blue 216. To tint it, you move each number toward 255, which is white. To shade it, you move each number toward 0, which is black. The percentage you choose decides how far you move.

The tint formula is: new value = current value + (255 − current value) × fraction. The shade formula is: new value = current value × (1 − fraction). The fraction is the percentage as a decimal, so 20 percent is 0.2. Round each answer to the nearest whole number, because RGB channels are whole numbers.

Work through a 20 percent tint of #3B7DD8 by hand. Red: 59 + (255 − 59) × 0.2 = 59 + 39.2 = 98. Green: 125 + (255 − 125) × 0.2 = 125 + 26 = 151. Blue: 216 + (255 − 216) × 0.2 = 216 + 7.8 = 224. So the 20 percent tint is rgb(98, 151, 224), which is #6297E0. Now the 20 percent shade: red 59 × 0.8 = 47, green 125 × 0.8 = 100, blue 216 × 0.8 = 173. So the 20 percent shade is rgb(47, 100, 173), which is #2F64AD.

Notice what the formulas do. In a tint, the channels that are already high move very little, because they are already close to white, while the low channels move a lot. That is why a tint of a blue gets paler without turning grey. In a shade, every channel shrinks by the same proportion, so the hue stays put while the colour darkens evenly. Both formulas keep the three channels in the same relationship to each other, which is what keeps the colour recognisable at every step.

The same method works for any base colour. Take a warm orange, #FF5733. Its 50 percent tint is rgb(255, 171, 153), or #FFAB99, a soft peach. Build a simple five-colour palette from one colour

A full nine-step scale is useful, but most small projects need only five colours. Here is a reliable way to pick them from the scale above, using the #3B7DD8 family as the example.

  1. Background: the 80 percent tint, #D8E5F7. Very light, so text sits comfortably on it, but still visibly blue, so the page does not look plain white.
  2. Surface or card: the 60 percent tint, #B1CBEF. Slightly stronger than the background, so cards and panels stand out from the page behind them.
  3. Accent: the base colour itself, #3B7DD8. Use it for buttons, links, and the one element on the page that should draw the eye.
  4. Hover or active state: the 20 percent shade, #2F64AD. A little darker than the base, so a button visibly darkens when the mouse hovers over it, without changing colour.
  5. Text: the 50 percent shade, #1E3E6C. Dark enough to read easily on white and on the light tints, and still blue, so the text belongs to the same family.

Five colours, one base, no guesswork. Use the light tints for large areas, the base for the few things that must stand out, and the dark shades for text and for states like hover and pressed. If you need a sixth colour, add the 40 percent tint as a border or divider, or the 70 percent shade for a footer. Resist the urge to use all nine steps on one page: a palette is a set of roles, not a collection, and each colour should have a job.

Where to use shades and tints on a website

Each step of the scale has a natural job, and putting a step in the wrong job is how designs go wrong. Light tints, from 70 to 90 percent, are for backgrounds and large areas: page backgrounds, section backgrounds, and the fill behind a highlighted box. They are light enough that dark text reads well on them, and they add colour without competing with the content.

Mid tints, from 30 to 60 percent, are for surfaces that sit on top of the background: cards, panels, badges, and table rows. They are strong enough to be noticed and light enough to carry dark text. The base colour itself is for accents: buttons, links, icons, and the one or two elements that should draw attention first. Because it is the strongest step, it should also be the rarest on the page.

Dark shades are for text and for emphasis. A 50 percent shade of a blue is dark enough to read as text on white and on light tints. Deeper shades, from 70 to 90 percent, are for footers, for text that must have maximum contrast, and for the pressed state of a button. A button that darkens by one or two shade steps when clicked feels responsive, and the change is visible without any new colour being introduced.

Hover states deserve a special mention, because they are the most common place a palette earns its keep. A button in the base colour that darkens to the 20 percent shade on hover tells the user it is clickable, and it does so with the same hue. A button that changes to a different colour on hover looks like a mistake. The same rule applies to links: a link in the base colour that darkens a shade on hover is enough.

The contrast rule: not every step works as text

A palette that looks good can still be unreadable, and the reason is contrast: how far apart the text colour and the background colour are. The Web Content Accessibility Guidelines, known as WCAG, ask for a contrast ratio of at least 4.5 to 1 for normal-sized text, and at least 3 to 1 for large text. A ratio of 1 to 1 means the text and the background are identical; higher is better.

The base blue #3B7DD8 against white has a contrast ratio of about 4.1 to 1. That passes the large-text bar of 3 to 1, but it fails the normal-text bar of 4.5 to 1, so it is fine for a big heading and not good enough for body text. Its 50 percent shade, #1E3E6C, against white is about 10.6 to 1, which passes comfortably for any size of text. That is why the darker shade, not the base colour, is the right choice for body text in the palette above.

The rule runs the other way too. White text on the base blue is also about 4.1 to 1, so a button with white text on a #3B7DD8 background is borderline for small text. White text on the 20 percent shade #2F64AD is stronger, and white text on the 50 percent shade is stronger still. When in doubt, darken the background a step or two, or darken the text a step or two, until the contrast is clearly comfortable. The Color Picker gives you the steps; the contrast rule tells you which step to use for text.

Common mistakes when making shades and tints

Mixing with grey by accident. A tone, mixed with grey, is duller than a tint or a shade of the same depth. If your light blue looks washed out and grey, you have probably made a tone, not a tint. Tints stay vivid because only white is added; tones lose saturation because grey is added. If you want a bright, clean light blue, use a tint. Save tones for muted, dusty looks where dullness is the point.

Using too many steps. A nine-step scale is a tool for choosing, not a palette. A page that uses seven different blues looks messy, because the eye cannot tell which blue means what. Pick five steps, give each one a job, and leave the rest unused. The unused steps are still useful: they are there when a new job appears, like a new section or a new state.

Putting text on a mid-tone. The middle of a scale, around the base colour, is the worst place for text. Body text needs a dark shade on a light background, or white on a dark shade. Text in the base colour on a white background is usually too light, and text in a mid tint on a mid shade is usually too close together. Check the contrast before you publish, not after someone complains they cannot read it.

Changing hue instead of lightness. If you make a "lighter blue" by picking a different blue from a chart, you may have changed the hue as well as the lightness. The result is a blue that leans purple or green next to your brand blue, and the mismatch is visible even if nobody can name it. A true tint changes only the lightness, which is why it always matches.

Forgetting the hover state. A button with no hover state feels dead, and a button whose hover state is a different colour feels broken. Build the hover state from the same scale, one or two shade steps darker, and the interaction feels intentional.

Using a tint as a border. A 90 percent tint is so close to white that it disappears as a border on a white page. Borders need a step with enough strength to be seen, usually a 20 to 40 percent tint or a light shade. If the border is invisible, it is not a border.

The HSL shortcut and CSS color-mix

There is a second way to think about shades and tints, using HSL instead of RGB. HSL describes a colour by hue, saturation and lightness. The base blue #3B7DD8 is hue 215 degrees, saturation 67 percent, lightness 54 percent. To make a tint in HSL, keep the hue and saturation and raise the lightness. To make a shade, keep the hue and saturation and lower the lightness. The Color Picker shows the HSL values alongside HEX and RGB, so you can use whichever system you prefer. The RGB formulas above and the HSL lightness change describe the same idea in two notations, and the results are close, though not always identical, because the two systems mix colour differently.

Modern CSS also has a built-in way to make tints and shades: the color-mix() function. Writing color-mix(in srgb, #3B7DD8 80%, white) mixes 80 percent of the base with 20 percent white, which is a 20 percent tint. Writing color-mix(in srgb, #3B7DD8 80%, black) gives a 20 percent shade. It is supported in current versions of the major browsers, and it is handy when you want the browser to calculate the steps. For a palette you plan to reuse across a site, though, fixed HEX values copied from the Color Picker are simpler: they work everywhere, in every browser, and in every design tool, with no CSS function needed.

Frequently asked questions

What is the difference between a shade and a tint?

A tint is a colour mixed with white, so it gets lighter. A shade is a colour mixed with black, so it gets darker. A tone is a colour mixed with grey, so it gets duller. All three start from the same base colour, and all three keep the same hue.

How do I make a tint of a colour?

Move each RGB channel toward 255, which is white. For a 20 percent tint, use new value = current value + (255 − current value) × 0.2 for each channel, and round to the nearest whole number. Or type the colour into TOOLZORQ's Color Picker and click the tint swatch you want.

How do I make a shade of a colour?

Move each RGB channel toward 0, which is black. For a 20 percent shade, multiply each channel by 0.8. For a 50 percent shade, multiply each channel by 0.5. Or use the Color Picker, which shows the shades as a palette you can copy from.

How many shades and tints should a palette have?

Five is enough for most small projects: a light background tint, a surface tint, the base colour as the accent, a darker shade for hover states, and a dark shade for text. More steps are available when you need them, but each colour on the page should have a job.

Can I use a tint for text?

Usually not. Light tints have too little contrast against a white background to read comfortably. Text should use a dark shade of the colour, or white text on a dark shade. The WCAG guide is a contrast ratio of at least 4.5 to 1 for normal text.

What is the HEX code for a tint or shade?

There is no single HEX code for "a tint" — the HEX depends on the base colour and the percentage. A 20 percent tint of #3B7DD8 is #6297E0, and a 20 percent shade is #2F64AD. Use the Color Picker to get the HEX for your own base colour at any step.
