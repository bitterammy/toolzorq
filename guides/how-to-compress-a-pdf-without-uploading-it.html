Why are some PDFs so large?

A PDF is a container, and what fills it decides its size. A document made mostly of typed text is usually small, because text takes up very little space. A document full of photographs, scanned pages or high-resolution images is a different story: each image can be far larger than all the text in the document put together.

Scanned PDFs are the worst offenders. A scanner does not see words — it sees a picture of a page, stored at whatever resolution the scanner used. A twenty-page scanned report can easily run to tens of megabytes, even though it holds nothing but black text on white pages.

What does "without uploading" actually mean?

Most websites that process files work on the server-side model: your browser sends the file to the website's server, the server does the work, and the result is sent back. For a PDF compressor, that means a copy of your document sits on somebody else's computer, even if only briefly — and you have to trust that it is deleted and that nobody else can see it.

"Without uploading" means none of that happens. The compressor is a small program that runs inside your own browser, on your own device. When you drop a PDF in, your device reads it, processes it, and hands the smaller PDF straight back as a download. No copy is sent anywhere, because there is nowhere for it to go.

High, Medium or Low — which quality should you pick?

The quality setting controls how much detail the tool keeps when it redraws each page as a smaller image: more detail means a larger file, less detail means a smaller one. The right choice depends on what you are doing with the file.

High quality is the best choice when appearance matters, or when the PDF will be printed. It keeps the most detail, so photographs stay sharp and small print stays readable. The file shrinks the least at this setting — the right price to pay for a document that needs to look good.

Medium quality is the sensible default for everyday jobs: attaching a document to an email, uploading it to a form, or sharing it in a message. The pages still look clean and readable, and the file is usually much smaller. If you are unsure, start here.

Low quality is for when size is the only thing that matters — a file that must fit under a strict upload limit, for example. It produces the smallest file, but the pages look noticeably softer, and fine print may become hard to read. Use it when the document only needs to be legible.

Which PDFs shrink the most?

Not every PDF compresses equally, and knowing what to expect saves disappointment. The rule is simple: the more of the file is made of images, the more there is to shrink.

Type of PDFWhat it containsLikely result
Scanned documentEvery page is a full-page imageShrinks the most — often dramatically
Image-heavy report or presentationPhotographs and graphics on most pagesShrinks a great deal
Mixed documentText with some images or chartsShrinks a moderate amount
Text-only documentTyped words, almost no imagesBarely shrinks at all

Scanned PDFs shrink the most because every page is an image, and images are exactly what this kind of compression reduces. Image-heavy PDFs — reports with photographs, slide decks, catalogues — behave the same way. A small text-only PDF may barely shrink at all: there are no large images to reduce, and the text itself is already stored efficiently. If your two-page letter comes back only slightly smaller, the tool has done its job correctly. As an illustrative example: a scanned 12-page PDF that starts at 8 MB might come down to around 2 MB at Medium quality — your own result will differ, because it depends on the resolution of the original scans. Treat that figure as a rough sense of scale, not a promise.

What happens to the text in your PDF?

This is the most important thing to understand about how this compressor works, so it is worth stating plainly: the pages become images, so the text is no longer selectable or searchable.

The tool shrinks your PDF by rendering each page to a smaller image and rebuilding the PDF from those images. The new PDF looks the same — the words are still there, in the same places — but they are now part of a picture of the page rather than live text. You can read them, but you cannot highlight a sentence, copy a paragraph, or search the document for a word.

For many uses, that does not matter: a scanned form, a signed letter or a photo-heavy report is usually read, not searched. But if you need to search the document later, copy text out of it, or use a screen reader, the compressed version will not do those things. Keep your original, and compress a copy for sending or sharing.

When should you NOT compress a PDF this way?

Compression is not always the right move, and knowing when to leave a file alone is as useful as knowing how to shrink it.

Do not compress a PDF you need to search or copy text from. The compressed pages are images, and the text inside them cannot be selected, copied or searched. If it is a contract you will search through or a report you will quote from, keep it in its original form.

Do not compress a PDF that will be printed at high quality. A compressed page looks fine on a screen, but printing magnifies every softened edge. A poster, a certificate or anything printed large deserves the original file.

Do not compress a PDF that is already small. A two-page text-only letter has almost nothing to gain: the compressor will return a file of roughly the same size, with the text turned into images for no benefit.

How to check for yourself that nothing was uploaded

You do not have to take any website's word for how it handles your files. There are two checks anyone can run, and both take less than a minute.

First, watch what your browser sends. Open the developer tools with F12, go to the Network tab, and compress a file. If the tool works in your browser, you will see no large upload leaving your device while it runs. A server-side tool, by contrast, shows your file travelling out as an upload before the result comes back.

Second, try it with the internet off. Load the PDF Compressor page, then disconnect — switch on aeroplane mode, or unplug the cable — and compress a file. A tool that runs entirely in your browser keeps working, because everything it needs is already on your device. A tool that needs a server stops at the upload step. Reconnect when you are done.

Common mistakes

Compressing the only copy. People compress a file, send it off, delete the original to save space, and only later realise they needed the searchable text or the print quality. Compress a copy; keep the original.

Choosing Low quality for a document that needs to be read carefully. Low quality suits a file that only needs to fit under an upload limit, but not a document full of small print, tables or diagrams. If the compressed file is hard to read, run the original again at Medium or High.

Expecting a text-only PDF to shrink. A short document of typed text is already small. If the result is barely smaller than the original, nothing has gone wrong — the file simply had no bulky images to reduce.

Compressing the same file over and over. Each round redraws the pages as images and loses a little more detail, so a compressed file only gets progressively softer. Always start each attempt from the original file.

Forgetting to check the result before sending it. The tool shows the original size, the new size and the percentage saved — but that tells you the numbers, not whether the pages still read well. Open the downloaded file and check the smallest print before you send it on.
